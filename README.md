# Onboarding Management

## Description
**Onboarding Management** provides a centralized solution for viewing, managing, and tracking onboarding records within NIM. The application enables administrators and authorized users to monitor onboarding activities throughout the onboarding lifecycle, ensuring new users are provisioned accurately and efficiently.

With a streamlined interface, users can review onboarding requests, update onboarding information, track progress, and manage onboarding records from a single location. By centralizing onboarding management within NIM, the application improves visibility, enhances operational efficiency, and helps ensure a consistent onboarding experience across the organization.

# Prerequisites
- [Standard Item Library](https://github.com/Tools4ever-NIM/NIM-Framework-ItemLibrary)
- [Framework Baseline v1](https://github.com/Tools4ever-NIM/NIM-Framework-Baseline)

# Installation
- Download app.json source file
- Within NIM
- 	Go to Apps
- 	Click Import
- 	Select app.json
-	Create each missing audit query
- 	Complete Import
- 	Under Apps, Uncheck "Exportable" if checked
